# 👨‍🎓 Inventory API

A RESTful API for managing products, categories, orders, and order items, built with Django REST Framework.



## 🎯 Features 

- Product management
- Category management
- Order management 
- Order item management
- JWT authentication 
- User authorization 



## 🧰 Tech Stack

- Python 3.10.2
- Django
- Django REST Framework 
- PostgreSQL
- Simple JWT 
- drf-spectacular
